# Wqeb
wqeb is online radio station, which online for 24/7 and 365 days .
this app is design to reach our channel voice to all mobile user through app.

# user data
we  collect user name,email,and maybe user profile image which necessary for basic authentication to our app,
when user apply for an account upgrade we collect username,phone,address and a file of user proof.
the user may request to delete his/ her data via https://wqeb973.app/contact-us.
# Payment Inforations
we use **Stripe** as payment plateform for buying products from our store,upgrade account fee,booking events , we dont't collect any user payment infromation directly.
**Stripe** handle all these.
